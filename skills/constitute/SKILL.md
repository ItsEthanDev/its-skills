# Constitute

Read existing governance and relevant project context. Distinguish accepted constraints from current implementation and feature-specific requirements. Ask about unresolved consequential choices; do not infer policy from code or promote a one-feature requirement into governance.

Use existing policy owners. Create `./CONSTITUTION.md` only when the project needs a consolidated owner and has none. When creating one, read [CONSTITUTION-FORMAT.md](CONSTITUTION-FORMAT.md).

Record accepted, actionable rules and an observable compliance signal. Obtain direction before adopting agent-proposed policy. If a proposed change conflicts with governance, surface the conflict rather than bypassing it.

Keep agent-specific operating instructions in the applicable `AGENTS.md` or harness equivalent. Point to canonical human-facing documentation for shared facts.

Reconcile directly affected specifications, plans, instructions, and checks. Verify changed paths, links, and commands at their sources.

Return the governance changes, unresolved decisions, and verification results. Stay within the assignment; establishing governance does not authorize further development.
