# Constitute

Use this stage when durable project constraints need to be established or amended within the assignment. Existing governance need not be recreated for every project change.

Read the current rules and relevant project context. Distinguish accepted constraints from accidental implementation and feature-specific behavior. Ask about consequential choices the project has not decided; do not silently promote a current behavior into policy.

Record accepted, actionable rules through [Project Documentation](../../../techniques/project-documentation/SKILL.md) in the project's authoritative owner, with an observable way to recognize compliance. Reconcile directly affected specifications and instructions.

The boundary is accepted governance, or an explicit unresolved decision, with its dependents accounted for. Handoff to Specify, Plan, or another applicable stage only when that work is within the request. Constitute is not a mandatory prerequisite when the governing decisions are already established.
